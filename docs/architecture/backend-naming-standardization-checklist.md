|---|---|

| UserExtraRoles | Needs type review before deciding whether this is entity/value object/DTO. |

## Phase Recommendation

1. Rename one high-risk sub-feature at a time.
2. Keep table names, column names, DTO fields, endpoint paths, security annotations, and migrations unchanged.
3. Update JPQL/HQL entity names when entity class names change.
4. Run mvnw.cmd -DskipTests compile after every sub-feature.
5. Run mvnw.cmd test after each module batch.
