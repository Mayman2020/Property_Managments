## 0) تجهيز قاعدة البيانات (مرة واحدة)

1. أعد تشغيل الـ **Backend** — Flyway يطبّق migration **V180** ويمسح كل البيانات التشغيلية.
2. **ما يُحذف:** عقارات، وحدات، مستأجرون، ملاك، عقود، صيانة، فواتير، HR، مالية، إشعارات، مستخدمون (غير الأدمن).
3. **ما يبقى:** Lookups، صلاحيات الأدوار، قوالب العقود، فئات المصروفات/الصيانة، **Super Admin** فقط.

## 10) تسلسل اختبار End-to-End مقترح (سيناريو واحد كامل)

```
1. Super Admin → عقار + 2 وحدة + مالك + شركة صيانة
2. Super Admin → مستأجر + عقد ACTIVE
3. Tenant → طلب صيانة
4. Officer → إكمال الزيارة (COMPLETED)
5. Tenant → تقييم الزيارة
6. Admin → /admin/ratings يظهر التقييم
7. Super Admin → عقد صيانة + فواتير شهرية
8. Accountant → دفع قسط + إيصال
9. Owner + Company → إشعار REQUEST_RATED / PAYMENT_RECEIVED
10. Accountant → عرض الإيصal من جدول الأقساط
```
